# TeamMatesIQ Documentation

This repository is the central source of truth for TeamMatesIQ strategy, architecture, product, UX, security, commercial, engineering, API, database and brand documentation.

## Documentation

See the [TeamMates canonical document register](docs/README.md).

## Repository structure

- `docs/` — business, product and delivery documentation
- `engineering/` — engineering backlog and architecture decision records
- `architecture/` — C4, sequence and entity-relationship diagrams
- `api/` — OpenAPI specifications
- `database/` — schemas and migrations
- `assets/` — brand assets and diagrams

## Working principles

- Keep important decisions traceable.
- Store documentation close to the work it governs.
- Use pull requests for substantive changes.
- Never commit secrets, credentials or customer data.
