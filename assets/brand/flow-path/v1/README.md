# TeamMatesIQ Flow Path production assets v1

This pack contains the approved **02 — Flow Path** identity rebuilt as precise SVG geometry.

## Included

- Corporate TeamMatesIQ lockups: primary, reversed and single-colour
- TeamMates endorsed product lockups: primary and reversed
- Flow Path symbol: colour, navy and white
- Light and navy application icons
- PNG exports for common digital uses
- A production proof and usage specification

All production SVG wordmarks use outlined letterforms, so they do not depend on an installed font. The artwork uses flat approved colours only; there are no gradients.
